# Cancer Diagnosis Prediction

## Overview
This project predicts cancer diagnosis in patients using machine learning. 
Built during the HNG Tech Data Analyst Internship (2023), it explores key 
risk factors and develops a predictive model to support early detection efforts.

## Dataset
- Source: Provided by HNG Tech Internship Programme (2023)
- 1,500 patient records
- 9 features: Age, Gender, BMI, Smoking, GeneticRisk, PhysicalActivity, 
  AlcoholIntake, CancerHistory, Diagnosis

## Tools & Libraries
- Python, Pandas, Seaborn, Scikit-learn, imbalanced-learn

## Project Workflow
- Exploratory Data Analysis (EDA)
- Class imbalance identification (63% vs 37%)
- Feature importance analysis
- Predictive modelling using Random Forest Classifier

## Key Findings
- BMI and Alcohol Intake were the strongest predictors of cancer diagnosis
- Model achieved 90% accuracy
- Projected cancer incidence for 2027: 13%
